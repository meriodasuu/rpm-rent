# RPM Rent — карта edge cases и результаты проверки

## Возраст и стаж

| Сценарий | Ожидание | Проверка |
|---|---|---|
| На день младше minimumAge | 422 DRIVER_NOT_ELIGIBLE | unit + реальный API |
| Ровно minimumAge в дату начала | допускается | unit + реальный API 201 |
| День рождения после начала | возраст ещё не наступил | unit |
| Рождение 29 февраля | полные годы без JS rollover | unit |
| Права выданы после начала | 422 | unit |
| Права раньше рождения | 422 | unit |
| Стаж на день меньше порога | 422 DRIVER_NOT_ELIGIBLE | unit + реальный API |
| Ровно N полных месяцев | допускается | unit + реальный API |
| Произвольное поле `drivingExperienceMonths` | mass assignment, 422 | schema/API |

## Даты и доступность

| Сценарий | Ожидание | Проверка |
|---|---|---|
| Начало сегодня | допускается | unit |
| Начало вчера | 422 | unit + API |
| `start == end` | 422 | unit + API |
| `end < start` | 422 | unit |
| Несуществующая дата | 422 | schema |
| ISO timestamp вместо даты | 422 | schema |
| Срок меньше car minimum | 422 | unit |
| Срок больше 366 суток | 422 | unit |
| Старт далее 730 дней | 422 | unit |
| Соседние `[a,b)` и `[b,c)` | не пересекаются | unit |
| Пересечение NEW/IN_PROGRESS/CONFIRMED | 409 | unit + API |
| Пересечение после CANCELLED/DECLINED/COMPLETED | допускается | unit |
| Занятая машина в каталоге | остаётся видимой с причиной | browser: 8 карточек, busy label |

## Деньги, услуги и история

| Сценарий | Ожидание | Проверка |
|---|---|---|
| Клиент прислал `rentalPrice`/`status` | strict 422 | unit + API |
| Неизвестная/снятая услуга | 422 | unit + API |
| Отрицательная/дробная/переполненная сумма | reject | unit |
| Изменили машину после заявки | snapshots не меняются | FileStore integration |
| Удаление машины с заявками | reject | FileStore integration + FK RESTRICT |
| Удаление использованной услуги | reject | store rule |

## Повторы, гонки и abuse

| Сценарий | Результат реального API |
|---|---|
| Два запроса с одним idempotencyKey | оба 201, один и тот же booking ID |
| Два одновременных пересекающихся запроса с разными ключами | один 201, один 409; в QA-базе одна запись периода |
| Девятый запрос за минуту с одного ключа rate limit | 429 |
| Неавторизованный `/admin/bookings` | redirect на `/admin/login` |

## Полный ручной прогон A–M

| ID | Сценарий | HTTP/видимый результат |
|---|---|---|
| A | возраст < 18 | 422 DRIVER_NOT_ELIGIBLE |
| B | ровно 18 и ровно 12 месяцев стажа | 201 |
| C | стаж на один день меньше | 422 DRIVER_NOT_ELIGIBLE |
| D | начало в прошлом | 422 VALIDATION_ERROR |
| E | нулевой период | 422 |
| F | пересечение с UI-заявкой | 409 BOOKING_CONFLICT |
| G | машина с ненастроенными правилами | 409 CAR_UNAVAILABLE |
| H | retry с тем же ключом | 201 + тот же ID, одна запись |
| I | mass assignment цены/статуса | 422 |
| J | неизвестная услуга | 422 VALIDATION_ERROR |
| K | конкурентная гонка | 201 + 409, одна запись |
| L | rate limiting | 9-я попытка 429 |
| M | подмена `source` | 422; сохранённые заявки имеют только `website_booking` |

Дополнительно браузер подтвердил: валидная форма показывает рассчитанные 37 лет / 84 месяца и success state; несовершеннолетний видит причину, submit disabled; каталог не скрывает занятый автомобиль; закрытый admin route требует вход. Все тестовые записи создавались в отдельной QA-базе, после проверки она удалена.
